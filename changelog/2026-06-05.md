## Notable Trends

1. **Geometry-appearance decoupling reaches 3DGS**: Geometry Gaussians introduces per-splat geometry opacity — a new parameter that separates "where is the surface" from "what does it look like". This directly addresses the long-standing problem that 3DGS conflates rendering opacity with geometric occupancy, which causes failures on transparent/thin objects. This is structurally similar to the user's SignedGS direction (signed opacity → decoupled geometry), suggesting convergence toward a unified formulation.

2. **Feed-forward 3DGS breaks pixel-grid coupling**: ZipSplat demonstrates that token-based representations (k-means clusters instead of per-pixel prediction) can reduce Gaussian count by 6× while improving quality. This challenges the implicit assumption in all prior feed-forward 3DGS methods that Gaussian count should scale with input resolution.

3. **Reflective/transparent 3D reconstruction benchmark established**: 3DReflecNet (CVPR 2026) finally provides a systematic benchmark showing that ALL current 3DGS/NeRF methods suffer catastrophic failure (PSNR drops >10 dB) on reflective, transparent, and low-texture surfaces. Three distinct failure modes are characterized — creating a clear research gap for the user's SignedGS/geometry-opacity direction.

4. **Autoregressive mesh generation rivals neural implicit**: MeshWeaver (CVPR 2026) and MeshFlow (CVPR 2026 Highlight) demonstrate that autoregressive next-vertex prediction and MeshVAE+flow can generate high-quality meshes (up to 16K faces) without implicit representations. This has direct implications for the cad-mesh-3dgs bridge pipeline.

5. **Physics-in-the-loop 3D scene reconstruction**: SimuScene integrates a physics engine as a diagnostic tool during generative 3D reconstruction — using gravity, collision, and stability as constraints. This parallels the broader trend toward physical consistency in 3DGS (user's SignedGS research direction).

6. **3D priors injected into VLA models**: 3DThinkVLA demonstrates that embedding latent 3D geometric representations into vision-language-action models via co-training yields SOTA on LIBERO. This directly supports the MCP protocol integration roadmap (v0.5) — 3D spatial understanding as a first-class capability in embodied agents.
