## Verification Protocol

1. Each arXiv ID fetched from `arxiv.org/abs/<id>`; method name must appear in the paper title or be the self-declared framework name in the abstract.
2. Venue taken from arXiv Comments field (e.g., "Accepted at ECCV 2026", "ECCV 2026 (Spotlight)") or Journal reference when present.
3. Entries without arXiv pages (Heat Kernel Textures, GRF-Recon, PriSplat) confirmed via ECCV 2026 official virtual program links and conference coverage; stored with empty arXiv ID and venue "ECCV 2026".
4. Cross-checked against existing database to prevent duplicates: ReSplat, SubSplat, TruncGradGS were already present and therefore skipped.
