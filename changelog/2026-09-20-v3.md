Evidence-grounded exemplar library. Every pattern is backed by direct quotes from the three benchmark papers.

**Cross-Cutting Patterns (10):**
1. Two-Sided Win Thesis — quality AND efficiency simultaneously, breaking an accepted trade-off
2. Diagnose Before Cure — mechanism-level failure analysis before solution
3. The "Sidestep" Move — eliminate a structural cost of the incumbent approach entirely
4. Theory Import — ground novelty in established theory (Nyquist-Shannon, EWA framework, Scene Representation Transformer)
5. Numbered Enumerations — "three key elements / three desirable properties" as memory anchors
6. Protocol Creation — invent evaluation settings when no benchmark tests your claim
7. Radical Transparency — disclose number provenance, hardware equivalence, community reimplementations
8. Caption-as-Takeaway — figure/table captions state conclusions, not just content
9. Nearest-Neighbor Surgical Separation — dedicated passage distinguishing from the single closest prior work
10. Honest Boundary Statements — quantified limitations with evidence pointers

**Section-Specific Patterns:**
- Title: 3 naming strategies (method+capability / catchy+problem / natural-language phrase)
- Abstract: all three follow Problem -> Gap -> "We [verb]" -> mechanism -> results -> impact
- Introduction: representation taxonomy opening / rhetorical question / field-context + specific failure
- Method: "obvious approach -> problem -> our solution" trust-building narrative
- Experiments: roadmap opening sentence, named ablation subsections
- Conclusion: challenge conventional wisdom with a quotable claim

**Pattern-to-Section Matrix:** Quick-reference table mapping each pattern to applicable sections.
