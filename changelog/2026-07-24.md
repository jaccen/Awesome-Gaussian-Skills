
# v0.5.0 — 2026-07-24

## Summary

MCP protocol implementation milestone. The `3dgs-mcp-renderer` skill specification (v0.7.1, 17 tools) has been implemented as a runnable MCP server with 24 tools (11 fully implemented, 13 schema stubs for advanced backends). Includes a Three.js WebSocket browser renderer and a 24-pattern voice intent mapper enabling natural language → MCP tool call closed-loop.

### Key Features

1. **Headless Mode**: Server runs without browser — scene operations work on in-memory state, render returns empty image
2. **Safety Gate**: Operations affecting >10% of Gaussians are logged with warning
3. **Synthetic Scene**: Default 10K Gaussian sphere generated on startup for immediate testing
4. **Auto-Reconnect**: Browser renderer auto-reconnects to WebSocket server on disconnect
5. **MCP Client Config**: Compatible with Claude Desktop, TeleClaw, and any stdio MCP client
