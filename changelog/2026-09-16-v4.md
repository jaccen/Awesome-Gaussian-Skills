# 2026-09-16-v4 · 主页精简重构：单页拆分为四页

## 动机

单页 `docs/index.html` 累积了 8 个板块（Hero / Text2Word / Img2GS / Showcase / 方法探索器 / 技能 / 安装 / 趋势）+ 约 3900 行 JS，全页 460KB / 4957 行。主页承载过多职责，访客第一屏之外的内容被淹没。按 UI 视角重新设计：**主页只做一件事——讲清楚这是什么、把人送到对的子页**。

## 新结构

| 页面 | 职责 | 体积 |
|---|---|---|
| `index.html` | 精简主页：Hero（版本徽章 / 标题 / 副题 / 3 数据胶囊 / 2 CTA）+ 4 张子页入口卡 + footer | **19.7KB**（原 460KB） |
| `methods.html` | 858 方法探索器（搜索 / 分类 / 排序 / 续载 / 弹窗 / 深链全功能保留）；**METHODS 数组迁至此页** | 364KB |
| `studio.html` | Text2Word + Img2GS + Showcase（PlayCanvas 按需加载不变） | 127KB |
| `skills.html` | 15 项技能 + 快速开始 + 研究热点 | 45KB |
| `app-common.js` | 共享 i18n（`AGS_T` / `applyStaticLang` / `setLang`）+ 子页标题键 + 导航 | 32KB |

## 兼容性处理

- **旧锚点重定向**：`index.html#methods` → `methods.html`，`#text2word / #img2gs / #showcase` → `studio.html`，`#skills / #install / #trends` → `skills.html`（保留 hash，`location.replace` 不留历史）。
- **子页标题**：`window.AGS_TITLE_KEY` 支持 `title.methods / title.studio / title.skills`，语言切换时同步切换 `<title>`。
- **setLang 逐函数守卫**：语言切换只重渲染当前页面存在的区块（如 skills 页只调 renderSkills/Install/Trends）。
- **知识库脚本联动**：`scripts/validate_knowledge_base.py`、`scripts/build_knowledge_base.py` 的 METHODS 解析/回写路径由 `docs/index.html` 改为 `docs/methods.html`；改后校验 **PASS（858 条，arXiv 747，代码链接 138）**。
- 导航统一：四页共用导航（首页 / 方法库 / 在线工作台 / 技能与安装 / 电子书 / 语言 / GitHub），当前页高亮；移除了旧导航里的 `localhost:5173` 开发残留链接（Studio 入口改为工作台卡片与 CTA）。

## 实现方式

- 拆分由生成器 `.temp/split_site.py` 完成：全部片段按行号从原文件**原文切片复用**（HTML 区块、METHODS 数据、探索器引擎、t2w/i2g/PlayCanvas 逻辑），不做手工重排，语法与行为风险最小。
- 拆分前原文备份：`.temp/index.html.pre-split.bak`。
