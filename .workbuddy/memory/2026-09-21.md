## 环境坑（重要）
- **bash heredoc 会吃掉反斜杠**：`cat > x.py <<'EOF'` 写入的正则里 `\\s` 变成 `/s`、`\\` 变成 `//`，
  脚本静默失效（表现为「methods.html 名称匹配 0 条」）。含正则/转义的脚本一律用 Write 工具写。
- 命令行内联 `python -c "...\""` 里的引号被 shell 破坏 → 同样改用脚本文件。
- `unesc = s.encode().decode("unicode_escape")` 会把 `³`/`é` 二次编码成 `Â³`/`Ã©`，
  解析 JS/HTML 字面量时只能用 `re.sub(r"\\(.)", r"\1", s)`。
