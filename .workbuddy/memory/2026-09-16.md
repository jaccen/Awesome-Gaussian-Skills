## docs/index.html 体验与稳定性重构

**任务**：index.html 存在问题，重新优化，做到好用流畅。

**根因（无头浏览器实测定位）**：`playcanvas.min.js` 压缩产物向 `window` 泄漏全局变量 `t`，
覆盖 i18n 函数 `window.t`；`applyStaticLang` 里 `el.textContent = undefined` 按 IDL 语义清空元素，
导致**全页 data-i18n 文案被清空、document.title 变 "undefined"、弹窗全是 UNDEFINED**。

**修复**（详见 `changelog/2026-09-16-v3.md`）
1. 翻译函数改名 `window.AGS_T`（26 处调用点），`window.t` 仅作兼容别名；`applyStaticLang` 空值加固。
2. PlayCanvas 改为按需加载（省 ~1.3MB 首屏），新增 `ensurePlayCanvas()` / `openScene()`，T2W+I2G 链路异步化。
3. 方法探索器重写：预建索引 + 160ms 防抖 + 分块渲染（首屏 48 张，哨兵续载）+ 自定义卡片 class +
   `content-visibility:auto`。**首屏 DOM 8310→1149（-86%），卡片标记 771KB→22.5KB（-97%）**。
4. 可用性：卡片改 `<a>` 可键盘/新标签、URL 状态 `?q=&cat=&sort=` 与 `#m=方法名` 深链、
   搜索高亮/清除/空态/`/`快捷键、弹窗焦点陷阱与 aria、「回到顶部」、`prefers-reduced-motion`。
5. 排序「引用 ↓」（citations 全 0，无效且卡片出现 `?0` 乱码徽章）替换为「名称 A-Z」「有代码」。
6. METHOD_DETAILS 移除 5 个黑名单残留死键；渲染层 `cleanName()` 把 `3DGS\u00B3` 归一化显示为 `3DGS³`。
   **总数保持 858，validate_knowledge_base.py PASS。**

**验证**：Playwright 全交互测试（搜索/分类/排序/续载/弹窗/Esc/深链/语言切换/PlayCanvas 懒加载/快捷键）全部通过，零 JS 错误。

**遗留待决策**
- `3DGS³` 在 methods.json/CSV/index.html 中重复两条（`3DGS\u00B3` Accel 无 arXiv vs `3DGS³` Dyn4D 2605.11489），
  页面已归一化显示，但数据层去重需把总数改 857 并联动 25+ 计数载体。
- `validator` 用 `casefold()` 查重，检不出「转义名 vs 真名」隐性重复，建议纳入 CI。
- `cdn.tailwindcss.com` 运行时 JIT 不宜生产使用，长期应预编译静态 CSS。

**可复用经验**
- **排查「页面文案莫名消失/标题变 undefined」先怀疑第三方脚本污染 `window`**（最小化引擎库常见）；
  `textContent = undefined` 会清空元素而非写入 "undefined"，这类 bug 极隐蔽。
- 内联 `<script>` 块可逐个抽出到临时文件用 `node --check` 做语法验证。
- playwright-core + 本机 Edge (`msedge.exe`) 可直接驱动，无需安装浏览器；
  配合 `--enable-unsafe-swiftshader` 可跑软件 WebGL。
- 大列表流畅三件套：预建小写索引（避免每次按键 toLowerCase）、分块/分页渲染、
  热路径用自定义 class 而非 Tailwind 原子类（Tailwind CDN 会对新 DOM 重新扫描编译）。
