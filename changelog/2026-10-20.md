## Method Highlights

- **HY-World 2.0** — Multi-modal world model producing navigable 3DGS worlds from text/image/video via four-stage pipeline (panorama generation + trajectory planning + world expansion). Advances HY-World 1.0.
- **F3DGS** — Federated 3DGS for decentralized multi-agent world modeling; shared geometric scaffold from registered LiDAR enables distributed reconstruction without centralized data aggregation.
- **4DGS-WAM** — Object-centric World Action Model on 4DGS; separately models dynamic objects (policy-predicted future states) and static background; bridges 4DGS reconstruction and future action prediction.
- **Cloth-Splatting** — 3D cloth state estimation via prediction-update framework; action-conditioned dynamics model + 3DGS state updates; mesh-Gaussian coupling for differentiable state-to-image map.
