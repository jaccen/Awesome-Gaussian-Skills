# 四方向 → 中文期刊落点映射（Chinese Venue Routing by Domain）

> **用途**：英文顶会未中或想先在国内发表时，按方向快速定位合适的中文期刊，并避开"投错刊"的常见错误。
> **适用**：3DGS / 具身智能 / 空间智能 / Agent 四方向及交叉方向。
> **整理日期**：2026-10-21
> **配套**：每本刊的具体格式规范见同目录 `<venue>-format.md`（cjc/jos/jcad/aas/scis/crad/jcis/cjig/pra/caai/vrih/jskx/jsjy/txxb/robot/jsjyyj/vciba 共 17 本）。
>
> ⚠️ **声明**：下表是**领域契合度判断**，不是录用难度排名，也不代表影响因子高低。各刊征稿范围会调整，**投稿前必须以期刊官网当期"征稿范围/栏目设置"为准**。本文件不提供分区、IF、录用率等易变数据（此类数据请查最新版 CCF 目录与期刊官网）。

## 1. 四方向落点矩阵

### 1.1 3DGS（渲染 / SLAM / 压缩 / 前馈 / 生成）

| 档位 | 期刊 | 契合理由 | 注意事项 |
|------|------|---------|---------|
| **首选** | 计算机辅助设计与图形学学报（JCAD） | 图形学与 CAD 主阵地，3DGS/神经渲染属核心征稿范围 | 重视几何与渲染的严谨性，图表规范要求高 |
| **首选** | 中国图象图形学报（CJIG） | 图像图形全覆盖，视觉类 3DGS 工作接受度高 | 需突出视觉任务价值，纯渲染加速需讲清应用 |
| **次选** | 计算机学报（CJC） | 综合性顶刊，要求方法有普遍意义 | 纯工程加速类不易过，需提炼方法论 |
| **次选** | 软件学报（JoS） | 若工作偏系统/工具链/开源框架 | 需强调软件工程价值与可复现性 |
| **次选** | 图学学报（TXB） | 几何建模、工程图学交叉 | 偏几何与工程应用更合适 |
| **交叉落点** | 虚拟现实与智能硬件（VRIH） | VR/AR 场景的实时渲染与压缩 | 需明确硬件/交互场景 |
| **交叉落点** | 工医艺的可视计算（VCIBA） | 可视化交叉应用 | 需有明确的可视分析或艺术/医学场景 |
| **应用向** | 计算机应用（JCA）/ 计算机应用研究（AROC） | 工程落地、系统实现 | 理论新意要求较低，重实用价值 |
| **不建议** | 自动化学报（AAS） | 控制/机器人导向 | 除非工作是 3DGS-SLAM 且控制贡献显著 |

> 细分到 26 个子类（Dynamic/Compression/SLAM/Editing…）的 venue 对应见 `3dgs-domain-venues.md` §1，本表只做方向级收敛。

### 1.2 具身智能（VLA / 机器人操作 / Sim2Real）

| 档位 | 期刊 | 契合理由 | 注意事项 |

| **首选** | 自动化学报（AAS） | 控制+智能系统+机器人综合，VLA 属热门 | 理论与系统完整性要求高，实验规模要求严 |
| **次选** | 智能系统学报（CAAI） | 智能系统与具身智能交叉 | 适合系统集成类，需讲清智能性 |
| **次选** | 模式识别与人工智能（PRAI） | 若贡献偏策略学习/表征学习 | 需突出学习方法的普适性 |
| **次选** | 中国科学:信息科学（SCIS） | 若工作有较强理论或范式意义 | 门槛高，需理论深度支撑 |

| **不建议** | 中文信息学报（JCIS） | NLP 导向 | 除非工作核心是语言指令理解 |

## 2. 交叉方向的落点规则

| 交叉类型 | 主贡献归属 | 推荐落点 | 判断依据 |
|---------|-----------|---------|---------|
| 3DGS + 具身 | 看**主贡献**在感知还是策略 | 感知为主 → JCAD/CJIG；策略为主 → 机器人/AAS | 主贡献决定期刊，另一侧作为应用叙述 |
| 3DGS + 空间智能 | 看**是否提出新任务/新表示** | 新表示 → JCAD/CJIG；新推理任务 → AAS/SCIS | 有新任务/新基准时优先综合刊 |
| 3DGS + Agent | 看**Agent 是否是主角** | Agent 主角 → CJC/JoS；3DGS 主角 → JCAD | 避免"两边都想要、两边都不深" |
| Agent + 具身 | 看**是否有真机闭环** | 有真机 → 机器人/AAS；纯仿真 → CAAI/PRAI | 真机是机器人刊的隐性门槛 |

> **核心原则**：交叉方向只报一个主贡献，另一侧写成"应用场景"。同时声称两个方向的主贡献，在中文期刊评审中常被判"定位不清"。

## 3. 怎么选：四步决策

```
① 你的主贡献是什么类型？
   理论/范式  → SCIS, CJC
   方法/算法  → CJC, JoS, PRAI, AAS（视方向）
   系统/工具  → JoS, CRAD, CAAI
   应用/落地  → JCA, AROC, JSKX
   数据集/基准 → CJIG, CJC（需配套方法）

② 你的实验是仿真还是真机/真实场景？
   仅仿真        → 避开机器人（Robot）
   有真机/实测   → 机器人、AAS 可冲

③ 你更看重周期还是层次？
   周期优先      → JSKX, AROC, JCA
   层次优先      → CJC, JoS, AAS, SCIS（周期通常更长）

④ 你的图表/可视化是否是核心论据？
   是 → JCAD, CJIG, TXB, VCIBA（图文规范要求高，但也更认可视化贡献）
```

## 4. 英文会议 ↔ 中文期刊的双向发表（合规提醒）

这是最容易踩红线的地方，务必按以下原则处理：

| 情形 | 合规要求 | 风险 |
|------|---------|------|
| 英文会议论文 → 扩展投中文期刊 | 必须**显著新增内容**（多数期刊要求新增实质章节/实验，常见口径为 30% 以上新内容），并在投稿时**主动披露**原会议版 | 未披露或新增不足 → 被判重复发表 |
| 中文期刊论文 → 扩展投英文会议 | 同样需显著新增并披露 | 版权归属需先确认（部分期刊版权归编辑部） |
| 同一工作中英文**同时**投两处 | ❌ 不允许 | 一稿多投，属学术不端 |
| 预印本（arXiv）→ 期刊 | 多数期刊允许，需确认目标刊预印本政策 | 少数期刊视为已发表 |

> **具体新增比例与披露格式以目标期刊"投稿须知"为准**，不要套用其他刊的规定。相关格式细节见对应 `<venue>-format.md`。

## 5. 中文期刊评审的几个现实差异（写作时就要照顾）

| 维度 | 中文期刊常见预期 | 对写作的影响 |
|------|----------------|-------------|
| 系统性 | 偏好"完整闭环"：问题—方法—实验—分析 | 英文会议可只讲一个点，中文刊常要求更完整的相关工作与方法推导 |
| 相关工作 | 篇幅更重，需覆盖国内同行工作 | 不能只引英文文献，需包含中文文献与国内团队工作 |
| 实验规模 | 常要求更充分的消融与对比 | 参见 `experiment-scale-thresholds.md`，中文刊通常不低于会议标准 |
| 图表规范 | 中英文图题、坐标轴单位、字号有硬性要求 | 投稿前按 `<venue>-format.md` 逐项核对 |
| 摘要 | 中文摘要 + 英文摘要，均需独立完整 | 英文摘要不是中文摘要的逐字直译 |
| 语言风格 | 本文/我们、由此/表明 等中文学术惯用语 | 避免英文句式直译导致的长定语堆叠 |
