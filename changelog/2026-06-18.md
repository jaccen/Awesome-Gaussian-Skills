
# Changelog — 2026-06-18

### Summary
Knowledge deepening update: no new methods added; enriched technical detail for 5 existing methods (RAF, ZipSplat, GaussianPile, Z-Order GS, 3DReflecNet) across 4 Skills based on multi-source article verification (Zhihu CVPR 2026 coverage, Baijiahao deep analyses, Leiphone RAF coverage, Tencent Cloud 3DReflecNet report). ### Methods Enriched (Detail Supplements, Not New Entries)

| Method | Source Article | Details Added |
|--------|---------------|---------------|
| **RAF** | Leiphone + visual-ai.github.io | 3-stage pipeline (asset abstraction→unified simulation kernel→visual recoupling); static collision mesh from Gaussian segmentation; opacity field→physics particle sampling; MPM/SPH/PBD/rigid-body/articulated-body multi-solver coupling; 5 heterogeneous interaction demos; UE5 Lumen rendering |
| **ZipSplat** | Baijiahao (ETH+Microsoft deep analysis) | Training stability: single-directional Chamfer geometry loss, coupled initialization (shared params per token group), progressive view scheduling (2→24 views), low initial opacity (~0.18); K-means token clustering cross-view merging (4.2 views/cluster at r=0.1);推理时压缩比可调旋钮; DA3-Giant backbone; 0.8s inference / 685 FPS rendering / 3.3MB storage at 24 views |
| **GaussianPile** | Baijiahao (CVPR 2026 coverage) | Focus-aware physical model with finite-thickness sensitivity map; additive rasterization (not alpha-blending) for volumetric intensity accumulation; 16-26× compression over voxel grids; 8min avg convergence; ABUS/LSM/MRI support; view-independent intensity (no SH for medical) |
| **Z-Order GS** | Bilibili/Zhihu (CVPR 2026 Oral coverage) | Confirmed CVPR 2026 Oral; Z-order (Morton) curve spatial indexing; sparse grouped+top-k attention reduces O(N²)→O(N log N); 1000× faster than per-scene optimization; 2-3× fewer Gaussians vs DepthSplat/AnySplat; cross-dataset generalization (RE10K/DL3DV→ACID); 2-12 variable input views |
| **3DReflecNet** | Tencent Cloud (Best Paper Candidate report) | Confirmed CVPR 2026 Best Paper Candidate; 120K+ synthetic + 1000+ real objects; 48 material combos; 3 quantified failure modes: (a) smooth metal PSNR 19dB vs rough 35dB (-45%), (b) transparent -5.82dB average, (c) low-texture 5dB span roughness 0→0.9; 5 tasks (matching/SfM/NVS/removal/relighting) |
