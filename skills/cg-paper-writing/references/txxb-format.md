
# 《图学学报》专项投稿撰写与格式指南

## 2. 收稿范围

图学理论、计算机图形学、CAD技术、工程图学、几何建模、可视化等

## 3. 投稿基本要求

- 来稿必须是**原创性论文**，结构完整、论点明确、论据可靠、论证合理、层次分明、可读性强。
- **不允许一稿多投**；不接受任何语种的翻译稿。
- 稿件属作者本人的创造性劳动成果，引用或参考他人的论述、数据、结果须将文献信息查新查全并在文中明确标引。
- 稿件应由投稿者单位审核无保密要求，可以公开发表。

### 特殊要求

中国图学学会主办；图学领域专业期刊

## 4. 论文结构要求

### 研究性论文

```
1 引言
  - 研究背景与意义
  - 现有工作不足
  - 本文贡献（分点列出）
  - 论文组织结构
2 相关工作（与引言独立）
  - 按主题分组
  - 每组末尾说明与本文的区别
3 方法 / 主要成果论述
  - 总体框架图 -> 逐模块展开
  - 每个新符号首次出现必须定义
  - 公式连续编号，引用格式：式(1)、式(2)
4 关键实现技术
5 实验 / 验证
  - 数据集、评价指标、基线方法
  - 主实验对比（表格）
  - 消融实验
6 结论
```

### 综述论文

应包括：**引言 → 问题与挑战 → 研究现状分析 → 未来研究方向 → 结论**。以分析、对比为主，避免堆砌文献。

## 5. 摘要撰写规范

中文摘要300字以内，包含目的、方法、结果、结论；英文摘要与中文对应

**贡献部分必须有数据支持**：不得出现"大大提高""显著改善"等定性描述；正确写法为"比…提高X%""在…上改善X%"。

**文字要求**：
- 尽量用短句；
- 描述作者工作用过去时，陈述结论用现在时；
- 用动词主动语态；
- 英文摘要与中文摘要内容对应；
- 摘要中不引用参考文献、不出现图表、不使用未定义缩写。

## 6. 关键词

5-8个，中英文对应，中英文一一对应，分号(;)分隔。

## 7. 参考文献要求

- 参考文献格式遵循 **GB/T 7714**（顺序编码制）。
- 参考文献应查新、查全并在文中明确标引。
- 与国内外同类工作进行详细讨论和比较。
- 期刊、会议、书籍名称不能用缩写。
- 中文文献用中文著录，英文文献用英文著录；中文文献需附英文对照。

### 格式示例

| 类型 | 格式 |
|------|------|

| 专著 | `[编号] 作者. 书名. 版次(初版不写). 出版地: 出版社, 年` |
| 学位论文 | `[编号] 作者. 题目[学位论文]. 单位地点: 单位名称, 年` |

## 8. 投稿前 CheckList

- [ ] 原创性确认：未在正式出版物刊载过，未一稿多投
- [ ] 题目简明反映思想和方法；中英文题目对应
- [ ] 摘要四要素齐全（目的→方法→结果→结论），贡献数据化
- [ ] 关键词5-8个，中英文对应，中英文一一对应
- [ ] 参考文献格式GB/T 7714，查新查全
- [ ] 插图精绘，有图序、图题和图注
- [ ] 公式符号规范（斜体/粗斜体），术语首次出现有全称
- [ ] 图学/CAD方向匹配
