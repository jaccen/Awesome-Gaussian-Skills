## Notable Trends
1. **Signal-aware density control matures**: CAdam (SIGGRAPH'26) uses statistical interference principle to separate geometric signal from generative noise, complementing LeGS/DeG/Learn2Splat in the trend toward learned density control
2. **Dynamic SLAM without semantics**: GGD-SLAM (ICRA'26) joins Flow4DGS-SLAM and WildGS-SLAM in removing semantic dependency for dynamic SLAM, using temporal attention instead
3. **Template-free avatar reconstruction**: PiG-Avatar decouples representation from body template topology, enabling layered clothing geometry as natural output
4. **Physics-informed clothing dynamics**: Latent Dynamics decomposes clothing motion into driving/restoring/dissipative forces, bridging data-driven and simulation-based approaches
5. **Multi-view 3D generation**: ROAR-3D upgrades single-view models to accept arbitrary unposed images via token-wise routing, enabling flexible view scaling
