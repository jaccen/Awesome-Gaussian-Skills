## 1. Tanks & Temples (T&T) 对比

**重要说明**：
- Mip-Splatting **未在T&T数据集上评估**（论文仅报告Blender和Mip-NeRF360）
- T&T对比限于 3DGS vs NegGS


### 1.1 T&T 数据集级别平均（7K / 30K 迭代）

来源：NegGS Table 2 **[A]**

| 方法 | 迭代 | PSNR ↑ | SSIM ↑ | LPIPS ↓ |
|------|------|--------|--------|---------|

| **NegGS** | 7K | **21.66** | **0.775** | **0.270** |

**NegGS vs 3DGS 差异**：

- 结论：NegGS在T&T上改善幅度约+0.4-0.5 PSNR，7K时改善更明显

## 2. Mip-NeRF 360 对比

### 2.1 数据集级别平均（7K / 30K 迭代）

来源标注：**[S]** = 服务器实际复现值，**[A]** = 论文原文提取，**[E]** = 估算值

| 方法 | 迭代 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | 数据来源 |
|------|------|--------|--------|---------|---------|
| 3DGS | 7K | 25.60 | 0.770 | 0.279 | NegGS Table 2 [A] |
| **3DGS** | **7K** | **25.89** | **0.771** | **0.276** | **服务器复现** **[S]** |
| **Mip-Splatting** | **7K** | **26.53** | **0.802** | **0.235** | **服务器复现** **[S]** |
| NegGS | 7K | 25.87 | 0.765 | 0.287 | NegGS Table 2 [A] |
| 3DGS | 30K | 27.21 | 0.815 | 0.214 | NegGS Table 2 [A] |
| **3DGS** | **30K** | **27.49** | **0.814** | **0.214** | **服务器复现** **[S]** |
| **Mip-Splatting** | **30K** | **27.97** | **0.838** | **0.175** | **服务器复现** **[S]** |
| NegGS | 30K | 27.39 | 0.812 | 0.219 | NegGS Table 2 [A] |

**LPIPS一致性关键说明**：

已验证：`lpipsPyTorch`（3DGS内置）与标准 `lpips` 包（`lpips.LPIPS(net='vgg')`）对**相同图像**算出的VGG LPIPS值几乎完全一致（差异 < 0.001），因此Mip-Splatting的LPIPS值可直接与3DGS对比。

之前记录的3DGS-30K LPIPS偏低（0.135/0.214）并非因lpips实现不同，而是因为：
1. **不同训练run的结果**：不同随机种子训练的模型PSNR/SSIM/LPIPS有自然波动
2. **渲染分辨率差异**：不同代码默认下采样策略可能不同（`resolution=-1`自动缩放 vs 指定scale）

**与NegGS论文的一致性**：
- 3DGS-7K服务器值PSNR=25.89 vs NegGS报告25.60（+0.29dB，训练随机种子差异）
- 3DGS-30K服务器值LPIPS=0.214 = NegGS报告0.214（完全一致，验证评估正确）
- 3DGS-7K服务器值LPIPS=0.276 vs NegGS报告0.279（差0.003，在正常范围）

**NegGS关键发现** **[A]**：
- NegGS在Mip-NeRF360上PSNR虽提升（+0.27/7K, +0.18/30K），但SSIM和LPIPS均**劣于3DGS baseline**
- 7K: SSIM 0.765 < 0.770, LPIPS 0.287 > 0.279（感知质量下降）
- 30K: SSIM 0.812 < 0.815, LPIPS 0.219 > 0.214（感知质量下降）
- 这表明负颜色值方法需兼顾PSNR和感知质量

## 6. 动态场景重建评价指标补充

> 以下指标在动态 3DGS 研究中广泛使用，补充至此文档以统一参考。

### 6.1 PSNR (Peak Signal-to-Noise Ratio)

| 属性 | 内容 |
|------|------|
| 全称 | 峰值信噪比 |
| 计算方式 | 基于像素级 MSE 反推，单位 dB |
| 取值范围 | [0, +inf)，越高越好 |
| 特点 | 最基础的图像质量指标；对感知质量不敏感；动态场景中常因运动区域误差拉低均值 |
| 使用数据集 | 全部数据集均使用 |

### 6.2 SSIM (Structural Similarity Index Measure)

| 属性 | 内容 |
|------|------|
| 全称 | 结构相似性指数 |
| 计算方式 | 基于亮度、对比度、结构三因子加权乘积，滑动窗口计算 |
| 取值范围 | [0, 1]，越高越好 |
| 特点 | 比PSNR更符合人眼感知；对结构变化敏感；动态场景中可反映形变保真度 |
| 使用数据集 | 全部数据集均使用 |

### 6.3 MS-SSIM (Multi-Scale Structural Similarity)

| 属性 | 内容 |
|------|------|
| 全称 | 多尺度结构相似性 |
| 计算方式 | 在多个下采样尺度上分别计算对比度和结构因子，加权融合 |
| 取值范围 | [0, 1]，越高越好 |
| 特点 | 比单尺度SSIM更鲁棒；对跨尺度结构失真更敏感；动态场景中可捕捉大尺度运动伪影 |
| 使用数据集 | HyperNeRF、Google Immersive 等密集多视角数据集常用 |

### 6.4 LPIPS (Learned Perceptual Image Patch Similarity)

| 属性 | 内容 |
|------|------|
| 全称 | 学习感知图像块相似度 |
| 计算方式 | 基于预训练深度网络（VGG/AlexNet/SqueezeNet）提取特征，加权L2距离 |
| 取值范围 | [0, +inf)，越低越好 |
| 特点 | 与人眼感知质量高度相关；对纹理和语义失真敏感；3DGS社区默认使用VGG backbone |
| 实现差异 | `lpipsPyTorch`（3DGS内置）与标准 `lpips` 包 VGG 值差异 < 0.001，可直接对比 |
| 使用数据集 | 全部数据集均使用 |

### 6.5 VMAF (Video Multi-Method Assessment Fusion)

| 属性 | 内容 |
|------|------|
| 全称 | 视频多方法评估融合 |
| 计算方式 | 基于SVM融合多个基础指标（ANSNR、DCT、Motion等）的机器学习模型 |
| 取值范围 | [0, 100]，越高越好 |
| 特点 | Netflix开发的视频质量评估标准；考虑时域一致性；动态场景重建中可评估帧间连贯性 |
| 适用场景 | 视频速率动态重建评估；长序列渲染质量评估 |
| 使用数据集 | Plenoptic Video、Google Immersive 等视频类数据集 |

### 6.6 FID (Frechet Inception Distance)

| 属性 | 内容 |
|------|------|
| 全称 | Frechet Inception 距离 |
| 计算方式 | 基于Inception网络提取的特征分布，计算两组图像集之间的Frechet距离 |
| 取值范围 | [0, +inf)，越低越好 |
| 特点 | 反映生成图像集与真实图像集的分布距离；适合评估整体渲染质量而非单帧 |
| 适用场景 | 数据集级渲染质量评估；生成式3DGS方法评估 |
| 使用数据集 | 需要大规模测试集的方法（生成式、前馈式动态3DGS） |

### 指标选择建议

| 评估场景 | 推荐指标组合 |
|----------|-------------|
| 基础对比实验 | PSNR + SSIM + LPIPS |
| 顶会标准协议 | PSNR + SSIM + MS-SSIM + LPIPS |
| 视频时域一致性 | PSNR + SSIM + LPIPS + VMAF |
| 生成质量评估 | FID + LPIPS |
| 感知质量优先 | LPIPS + MS-SSIM |
