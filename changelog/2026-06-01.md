## Notable Trends

1. **View-dependent rendering kernels challenge fixed covariance**: View-Dependent Splatting Kernels (SIGGRAPH 2026) learns per-view kernel shapes, replacing the assumption that each Gaussian has a single fixed 2D covariance regardless of viewing angle. This directly addresses the long-standing limitation that specular reflections and view-dependent effects require excessive Gaussian primitives in standard 3DGS.

2. **Apple enters 3DGS head reconstruction at scale**: HeadsUp demonstrates UV-parameterized 3DGS trained on 10,000+ subjects — the largest-scale feed-forward 3DGS head model to date. The UV parameterization pattern (decoupling Gaussian count from input resolution) is likely to transfer to other body parts and objects.

3. **Inference-time compute scaling for 3D reconstruction**: DéjàView introduces the concept of a compute knob K for 3D reconstruction, analogous to inference-time scaling in LLMs. This bridges the test-time compute paradigm from language to 3D vision.

4. **Generative 3D priors meet physics simulation**: SAM3D-Phys combines SAM3D generative 3D completion with physics-constrained optimization, enabling simulatable object recovery from reconstructed scenes. This completes the reconstruction→simulation pipeline that has been missing.

5. **Active NIR sensing for robust inverse rendering**: Ambient-Robust Inverse Rendering introduces active RGB-NIR imaging for material decomposition, extending the 3DGS relighting ecosystem beyond passive RGB-only approaches.

6. **3D-aware segmentation eliminates video dependence**: Gaga eliminates the assumption of continuous view changes for 3DGS segmentation, enabling robust per-object grouping from sparsely sampled photos — critical for real-world capture scenarios.

### New 3DGS/CAD/Mesh Spatial Agent Skills (v0.4)
- **`3dgs-spatial-agent`**: Domain-specific Agent skill bridging 3DGS reconstruction + CAD modeling + Mesh processing
  - Scene-level reasoning: Given reconstructed 3DGS, infer object parts, materials, articulation
  - CAD-in-the-loop: Integrate build123d/Open Cascade for parametric model extraction
  - Multi-modal I/O: Text/prompt → parameterized CAD model or 3DGS scene editing
  - Fills the gap in Scientific Agent Skills for 3D vision (no existing 3D-specific skills in Anthropic/OpenClaw ecosystems)

### MCP Protocol + 3DGS Rendering Integration (v0.5)
- **Goal**: Agent directly controls Three.js/3DGS rendering parameters via MCP
- **Architecture**: 
  ```
  Voice/Prompt → Agent → MCP Server → Three.js/3DGS Renderer
                                 ↓
              Camera params, Gaussian properties, Material settings
  ```
- **Key integration points**:
  - MCP tool: `set_camera_position(x, y, z,look_at)`
  - MCP tool: `modify_gaussian(id, opacity, color, scale)`
  - MCP tool: `render_frame(width, height)` → returns base64 image
  - MCP tool: `import_ply(path)` → loads 3DGS scene
  - MCP resource: `scene_info` → returns Gaussian count, bbox, categories
- **Voice-driven reconstruction**: Whisper → text → Agent → MCP → rendering parameter adjustment
