# 2026-09-16 (v3) — docs/index.html 体验与稳定性重构

## 背景

用户反馈 index.html「存在问题，不好用不流畅」。经无头浏览器实测定位，根因是
**PlayCanvas 引擎压缩产物向 `window` 泄漏全局变量 `t`**，覆盖了 i18n 翻译函数 `window.t`。
由于 `applyStaticLang` 执行 `el.textContent = undefined`（IDL 语义：undefined → null → 清空子元素），
导致**页面所有 `data-i18n` 文案被整段清空**：`document.title` 变成字符串 `"undefined"`、
导航/章节标题/统计徽章全部消失、方法详情弹窗里出现 "UNDEFINED / undefined"。

## 修复

### 1. i18n 命名冲突（根因）
- 翻译函数改名 `window.t` → `window.AGS_T`，全部 26 处调用点同步替换；
- `window.t` 保留为兼容别名，并在 PlayCanvas 懒加载完成后再赋值一次；
- `applyStaticLang` 对翻译结果做空值加固（`v == null ? '' : String(v)`），
  即便未来再次出现空翻译也不会清空页面。

### 2. PlayCanvas 按需加载（性能 + 根治）
- 移除 `<script defer src=...playcanvas.min.js>`（约 1.3MB，首屏不需要）；
- 新增 `loadPlayCanvasLib()` / 全局 `ensurePlayCanvas()` / `openScene(url,label)`，
  仅在用户点击 3D 预设或场景下拉时才拉取引擎；
- `initPlayCanvas` / `i2gInitPC` 增加 `window.pc` 守卫，T2W 与 I2G 两条链路全部异步化。

### 3. 方法探索器重写（流畅度）
| 指标 | 改造前 | 改造后 |
|---|---|---|
| 首屏 DOM 节点 | 8310 | **1149**（-86%） |
| 卡片标记体积 | 771 KB | **22.5 KB**（-97%） |
| 首屏渲染卡片 | 858 张 | 48 张（哨兵自动续载，48→96→…） |
| 搜索 | 每键全量重渲染 858 张 | 预建索引 + 160ms 防抖 |

- 卡片改用自定义 class（`.mc*`），绕开 Tailwind 运行时对 858 个节点的类名重扫；
- `content-visibility: auto` 让视口外卡片跳过渲染；
- 移除 `METHODS.indexOf(m)` 的 O(n²) 调用，改为携带原始下标。

### 4. 可用性
- 卡片由 `<div onclick>` 改为 `<a>`：可 Tab 聚焦、中键/Ctrl 新标签打开、可复制深链；
- 状态写入 URL（`?q=&cat=&sort=`），可分享、刷新还原；详情支持 `#m=方法名` 深链直达；
- 搜索命中高亮 `<mark>`、清除按钮、空态提示 + 一键重置、`/` 快捷键聚焦、Esc 关闭；
- 排序从「引用 ↓」（citations 全为 0，实际无效且卡片显示 `?0` 乱码徽章）替换为
  「名称 A-Z」与「有代码」；
- 弹窗：焦点陷阱、`aria-hidden`、滚动条宽度补偿、标签改为语义化 `<button>`；
- 新增「回到顶部」按钮；`prefers-reduced-motion` 降级。

### 5. 数据层（不动计数）
- METHOD_DETAILS 移除 5 个与仓库伪造黑名单一致但未清理的残留键：
  `GS-LRM-v2`、`GS-LRM-full`、`MVSplat-v2`、`GPSGaussian-Stereo`、`GaussianCross`
  （这些键从未被渲染命中，属死数据）；
- 渲染层新增 `cleanName()` 归一化：`3DGS\u00B3` 这类把 `\uXXXX` 转义字面量写进方法名的
  条目，展示为 `3DGS³`；
- **方法总数保持 858**，`scripts/validate_knowledge_base.py` 通过
  （858 / arXiv 747 / 代码链接 138，三载体一致）。

## 遗留问题（需另行决策）

1. **`3DGS³` 重复条目**：`data/methods.json` / CSV / index.html 中同时存在
   `3DGS\u00B3`（Acceleration，无 arXiv）与 `3DGS³`（Dynamic & 4D，2605.11489）两条，
   实为同一论文。页面已归一化显示，但数据层去重会把总数改为 857，
   需联动 25+ 个计数载体，建议单独执行。
2. `validator` 的去重检查用 `casefold()`，检不出这种「转义名 vs 真名」的隐性重复；
   建议把「转义字符残留」「渲染名重复」加入 CI。
3. `cdn.tailwindcss.com` 是运行时 JIT，控制台持续告警不应在生产使用；
   长期应预编译静态 CSS。
