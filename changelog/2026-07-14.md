## New Methods (21)

### Foundation / Optimization (2)
- **SalientGS** [arXiv:2607.11285] — Unified SfM-to-3DGS pipeline with MCMC Gaussian allocation; salient-guided density control
- **DP-Splat** [arXiv:2607.10912] — Bayesian nonparametric complexity control via Dirichlet-process prior; automatic Gaussian count determination

### Dynamic / 4D (3)
- **Grassmannian Splatting** [arXiv:2607.10489] — Rank-2 spacetime surfels with closed-form motion model; Grassmannian manifold optimization
- **MoE-GS / MoDE** [arXiv:2607.08250] (TPAMI 2026) — Mixture-of-Experts for dynamic Gaussian deformation; expert routing per motion pattern
- **CAGS** (SIGGRAPH 2026) — Color-adaptive volumetric video streaming with dynamic 3DGS; VQ + LoD adaptive streaming

### Feed-Forward / Generalizable (3)
- **HyperGS** [arXiv:2607.11500] — Feedforward optimization-free Gaussian video; 10^4–10^5× speedup over optimization-based methods
- **MAC-Splat** [arXiv:2607.10792] (ECCV 2026) — Multi-Attribute Consistency for feed-forward splats; +4.5 dB over Splatt3R
- **AsySplat** [arXiv:2607.10995] — Asymmetric geometry/appearance decoupling; ~800× speedup via async optimization

### SLAM (4)
- **GeoGS-SLAM v2** [arXiv:2607.11184] — Monocular SLAM with geometric priors; improved depth regularization
- **AnythingReality** [arXiv:2607.09260] — Online GS SLAM + VR + VLM; real-time spatial understanding
- **Track2Map** [arXiv:2607.08408] (MICCAI 2026) — Surgical GS SLAM; instrument tracking → 3D map for minimally invasive surgery
- **GeoGS-SLAM** (original) already in v0.4.1; v2 adds geometric priors

### Geometry / Surface (2)
- **HoloTetSphere** [arXiv:2607.08398] (ECCV 2026) — TetSphere mesh representation bridging 3DGS and physics simulation; volumetric TetSphere → tetrahedral mesh
- **Incremental 3D Gaussian Triangulation** — Progressive mesh extraction from 3DGS with topological guarantees

### Semantic / Segmentation (3)
- **CoSAG** [arXiv:2607.10237] — Training-free semantic compression; 37–76× over LangSplatV2 with zero fine-tuning
- **StructSplat** [arXiv:2606.28321] (ECCV 2026) — Camera-free sparse-view 3DGS via structural priors
- **MAC-Splat** also contributes to semantic consistency

### World Model / Spatial Intelligence (1)
- **ABot-3DWorld 0** [arXiv:2607.11673] — Universal world model → 3DGS; agent-driven 3D_scene understanding and generation

### Application / Cross-Domain (4)
- **PEAR** (SIGGRAPH 2026) — Single-image 100 FPS human avatar; pose-conditional efficient avatar reconstruction
- **PanoLOG** [arXiv:2607.08769] — Panoramic outdoor partitioning + Pano360 benchmark; large-scale outdoor GS
- **SyncSpace** [arXiv:2607.10050] — MR space reskinning via layout-conditioned GS; fast scene re-styling
- **FreDeGS** (Springer 2026) — Frequency-guided deblurring GS; motion blur → sharp 3DGS

### Robotics (1)
- **SplatCtrl** [arXiv:2607.08948] (ICRA 2026) — GS + reactive robot control; Gaussian-world-based behavior planning

### Sensing (1)
- **StereoSplat+** [arXiv:2607.08808] (IROS 2026) — Stereo + diffusion progressive GS; depth-guided densification

## Notable Trends

- **Bayesian nonparametrics** entering 3DGS: DP-Splat introduces Dirichlet-process prior for automatic complexity control — no more hand-tuned density parameters
- **Mixture-of-Experts for deformation**: MoE-GS/MoDE (TPAMI 2026) applies expert routing to dynamic Gaussian deformation patterns
- **Feedforward generalizable acceleration**: HyperGS achieves 10^4–10^5× speedup; MAC-Splat pushes +4.5 dB over Splatt3R — feedforward methods are becoming production-viable
- **Surgical GS SLAM**: Track2Map (MICCAI 2026) opens surgical scene reconstruction domain
- **Training-free semantic compression**: CoSAG achieves 37–76× compression over LangSplatV2 with zero fine-tuning — paradigm shift from trained semantic fields
- **SIGGRAPH 2026 video/volume focus**: PEAR (100 FPS avatars), CAGS (adaptive streaming) signal real-time volumetric video maturity
