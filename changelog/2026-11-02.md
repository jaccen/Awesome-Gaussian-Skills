## Method Highlights

- **LucidLyra** — First feed-forward framework making generatively reconstructed 3D scenes directly queryable for semantics and instances (open-vocabulary segmentation, object grouping) by distilling a video-diffusion model and frozen 2D foundation models into 3D Gaussians; extends to dynamic scenes from monocular video.
- **SplatLab** — First autonomous-research system demonstrated end-to-end in 3DGS: reproduces baselines, proposes extensions, trains/ablates across Mip-NeRF 360 and LLFF, writes manuscripts with every number bound to a logged run.
- **GEMS** — Persistent spatio-temporal 3DGS map + agentic reasoning pipeline for long-term semi-static scene memory; renders on demand to answer spatio-temporal questions.
- **ReferGaussian** — Unified 4DGS framework for referring segmentation: EntityBank of language-addressable Gaussian entities + MLLM query decomposition, training-free grounding.
- **MIMO-GS** — First MIMO channel-rendering GS: paired TX/RX 3D Gaussians + beam-pair splatting renders beam power maps 5.5× faster than ray tracing.
- **PriorGS** — Single-exposure HDR NVS with pseudo-HDR supervision priors and learnable CRF re-exposure.
- **GOFish** — First GS surface reconstruction trained directly on fisheye images with >180° FoV rasterization and aligned mesh extraction.
- **CTBakeGS** — Training-free conversion of CT volume renderings into 3DGS in about a minute on ordinary laptops (2M splats, 68 FPS).
- **ParetoGS** — Continuous-budget GS from sparse adapted anchors; nested budgets decoded from a compact residual atlas.
- **BoundedGS** — Bounded rasterization working set keeps memory ~1.07 GiB from 1K to 16K resolution (82.3% mean reduction on native 5K scenes).
