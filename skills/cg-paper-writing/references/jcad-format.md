## 2. 期刊定位与收稿范围

本刊是我国计算机辅助设计和计算机图形学领域**第一个公开出版的学术刊物**，面向全国，刊登有创新的学术论文，报道最新科研成果和学术动态。

**收稿范围**（包括但不限于）：
- 计算机图形学（图形算法与技术）
- 计算机辅助设计与制造（CAD/CAE/CAM）
- 几何造型与处理
- 可视化与可视分析
- 虚拟现实/增强现实/混合现实（VR/AR/MR）
- 三维图形计算
- 交互技术
- 图像视频处理
- 图像与图形的融合
- VLSI 设计与测试及电子设计自动化

**特色栏目**：前沿观点、Fast Track（鼓励前瞻性、引领性论文及重大突破性成果）。

## 3. 投稿基本要求

- 来稿必须是**原创性论文**，具有创新性，结构完整、论点明确、论据可靠。
- **不允许一稿多投**；文责自负，内容不得抄袭或重复发表。
- 投稿即视为同意将版权转让给编辑部，编辑部有权对稿件进行必要的修改和编辑。
- 通过学报官网在线投稿系统提交；建议使用 Word 格式。
- 合著稿件在署名时须征得其他作者同意，并确定好作者顺序。
- 注明作者姓名、单位、职称或职务、联系方式及邮寄地址。

## 4. 字数与篇幅

- 投稿时无严格字数限制，建议正文 6000-10000 字（不含参考文献）。
- 综述论文可适当加长。
- 录用后按编辑部修改通知调整篇幅。

## 5. 论文结构要求

### 研究性论文

```
1 引言
  - 研究背景与意义
  - 现有工作不足
  - 本文贡献（分点列出）
  - 论文组织结构
2 相关工作（与引言独立）
  - 按主题分组，不是按论文列举
  - 每组末尾说明与本文的区别
3 方法 / 主要成果论述
  - 总体框架图 → 逐模块展开
  - 每个新符号首次出现必须定义
  - 公式连续编号，引用格式：式(1)、式(2)
4 关键实现技术
  - 系统实现/实验应有关键点的详细论述，便于读者重复实现
5 实验 / 验证
  - 数据集、评价指标、基线方法
  - 主实验对比（表格）
  - 消融实验
  - 效率分析 / 可视化分析
6 结论
```

### 综述论文

应包括：**引言 → 问题与挑战 → 研究现状分析 → 未来研究方向 → 结论**。
以分析、对比为主，避免堆砌文献或一般性介绍。

## 6. 首页要素与格式规范

| 要素 | 要求 |
|------|------|
| 文题（中文） | 简明、醒目，准确概括论文主要内容；中文一般**不超过 20 字** |
| 文题（英文） | 与中文对应（非音译） |
| 作者 | 真实姓名，多个作者用逗号分隔；上标标注单位序号 |
| 单位 | 详细工作单位（含系/研究所，名称准确）、城市、邮政编码 |
| 中文摘要 | **250-300 字**，报道性文摘，包含四要素：**目的→方法→结果→结论** |
| 英文摘要 | 与中文摘要对应，准确表达论文主要内容和创新点 |
| 关键词 | **4-7 个**，选择贴近文义的规范性单词或组合词；中英文对应 |
| 中图法分类号 | 需标注 |

> 具体字体字号以官网"下载区"模板为准。投稿时重点关注内容完整性和可读性；录用后按编辑部修改通知调整格式。

## 7. 写作要求

1. 标题层次清晰明了，采用以下序号格式标注：
   - 第一级：`一、`
   - 第二级：`（一）`
   - 第三级：`1.`
   - 第四级：`（1）`
2. 摘要写成**报道性文摘**，具有独立性与自含性，能反映论文主要内容和创新点。
3. 英文摘要与中文摘要相对应，准确表达论文主要内容和创新点。
4. 术语首次出现给出"中文全称(英文全称, 缩写)"格式，如"三维高斯泼溅(3D Gaussian Splatting, 3DGS)"。
5. 公式中的变量用斜体，矩阵/向量用粗斜体。
6. 公式引用用"式(1)"而非"Eq.(1)"；图表引用用"如图 1 所示""见表 2"。
7. 插图精绘，图中文字清楚，应有图序、图题和图注。
8. 注释是作者对标题和正文中某一特定内容的解释或补充说明，须放置在**当页地脚**；注释序号与文中标注序号一致（文中标注序号用上标），一律用阿拉伯数字加圆圈标注（如①②③）。

## 8. 参考文献要求

### 核心规则

- 参考文献格式遵循 **GB/T 7714**（顺序编码制）。
- 参考文献应查新、查全并在文中明确标引。
- 与国内外同类工作进行详细讨论和比较。
- 期刊、会议、书籍名称不能用缩写。
- 建议引用本刊近 3 年相关论文。
- 中文文献用中文著录，英文文献用英文著录；中文文献需附英文对照。

### 格式（GB/T 7714 顺序编码制）

| 类型 | 格式 |
|------|------|
| 期刊 | `[编号] 作者. 题目. 刊名, 年, 卷(期): 起止页码` |
| 会议 | `[编号] 作者. 题目//会议名称. 出版地: 出版社, 年: 起止页码` |
| 专著 | `[编号] 作者. 书名. 版次(初版不写). 出版地: 出版社, 年` |
| 学位论文 | `[编号] 作者. 题目[学位论文]. 单位地点: 单位名称, 年` |
| 电子文献 | `[编号] 作者. 题目[文献类型/载体类型]. 网址, 发表/更新日期` |
| 中文文献对照例 | `陈涛, 杨启亮, 陈寅. 神经辐射场技术及应用综述. 计算机辅助设计与图形学学报, 2025, 37(1): 1-20 (in Chinese)` |

文献类型标识代码：M——专著，C——论文集，N——报纸文章，J——期刊文章，D——学位论文，R——报告，S——标准，P——专利，Z——其他。

## 9. 摘要撰写规范

摘要必须包含四要素（报道性文摘）：

1. **目的**：本文要解决的问题，开头明确交待；
2. **方法**：解决问题的方法及过程，结合论文中的公式、实验框图阐述；
3. **结果**：主要结果及结论，结合图表数据说明，言之有物；
4. **结论/创新**：本文的创新、独到之处，明确可定位。

**贡献部分必须有数据支持**：不得出现"大大提高""显著改善"等定性描述；正确写法为"比…提高 X%""在…上改善 X%"。

**文字要求**：
- 摘要字数控制在 **250-300 字**；
- 具有独立性与自含性，能反映论文主要内容和创新点；
- 英文摘要与中文摘要对应，准确表达主要内容和创新点；
- 摘要中不引用参考文献、不出现图表、不使用未定义缩写。
