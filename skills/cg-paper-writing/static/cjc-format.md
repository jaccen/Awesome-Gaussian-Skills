
# 《计算机学报》专项投稿撰写与格式指南

## 1. 投稿基本要求（先决条件）

- 修改稿必须符合学报模板要求；排版采用 MS Word，文章应有页码。
- 返回修改稿时须同时附 **DOC 和 PDF** 两种格式（通过编辑部通知邮箱发送）。
- 稿件首页：题目、真实姓名、详细工作单位（含系/研究所，名称准确）、城市及邮政编码、中文摘要、5-7 条关键词。
- 文末附：英文题目、汉语拼音姓名、工作单位英文译名（要求准确）、**500 单词以上**的英文摘要、5-7 条与中文关键词对应的英文关键词。
- 文后附联系人电话（手机）和 E-mail；各种基金资助课题论文须附项目号。

## 2. 论文结构要求

### 研究性论文（正文主体六部分）

1. **引言**：重点论述研究的科学问题、意义、解决思路、价值、贡献等；
2. **相关工作**：为与引言**相互独立的一个章节**（不可合并）；
3. 主要成果论述；
4. 关键实现技术（系统实现/实验应有关键点的详细论述，便于读者重复实现）；
5. 验证（对比实验或理论证明；实验应有具体环境设置、全面细致的数据对比分析）；
6. 结论（结束语）。

### 综述论文（本技能服务对象）

应包括：**引言 → 问题与挑战 → 研究现状分析 → 未来研究方向 → 结论**。
以分析、对比为主，**避免堆砌文献或一般性介绍、叙述**。

### 通用要求

- 定理证明、公式推导、大篇幅数学论述、原始数据一律放到论文**最后的附录**中。
- 正文需语句通顺、无中英文语法错误、符号使用正确、图表清晰无误。

## 5. 正文撰写 14 项硬性要求

1. 题目明确反映文章的思想和方法，文字流畅、表述清楚；
2. 中文文字、英文表达无语法错误；
3. 公式无符号、表达式的疏漏，**同一符号不得表示两种意思**；
4. 数学中使用的符号、函数名用**斜体**；
5. 使用量符合法定计量单位标准；
6. **矢量/向量、矩阵为黑体，标量为白体**；
7. 变量或表示变化的量用斜体；
8. 图表规范，量、线、序无误，位置正确——图表必须在正文中有所表述后出现（如"…如图 1 所示"）；纵横坐标应有坐标名称和刻度值；
9. 列出的参考文献必须在文中按顺序引用（引用顺序与编号顺序一致），各项信息齐全；
10. 首次出现的缩写需写明全称，首次出现的符号需作出解释；
11. 图的图例说明、坐标说明全部用中文或量符号；
12. 图应为**矢量图**；
13. 表中表头文字采用中文；
14. 公式尺寸：标准 10.5 磅；下标/上标 5.8 磅；次下标/上标 4.5 磅；符号 16 磅；次符号 10.5 磅。

附加：组合单位采用标准格式，如 `pJ/bit/m4` 应为 `pJ/(bit·m4)`。

## 5b. 定理与算法排版

- `定理1.` 内容 — 排版格式同"定义"、"假设"、"公理"、"引理"等；证明过程同"例 x"格式，结尾对齐"证毕。"。
- 详细定理证明、公式可放附录。
- 过程/算法描述：关键字（IF、THEN 等）全部大写，变量和函数名斜体。

## 6. 参考文献格式（含空格与标点，句号除外，严格照抄）

**正文引用格式**：采用 GB/T 7714 顺序编码制，引用编号用**右上角标**标注，如 `研究表明[1]`；同一处引用多篇文献时用逗号分隔，如 `[2,3]`。


> 关键规则：网上的文献一般**不作为参考文献**，可作脚注（脚注放于正文出现处，**每页从 1 开始编号**）。中文参考文献需给出**中英文对照**。期刊、会议、书籍名称**不能用缩写**。编辑部会核查文献信息，信息不正确予以删除；**关键性文献信息不正确，文章不予发表**。

| 类型 | 格式 |
|------|------|
| 期刊论文 | `[编号] 作者(外国人姓在前，名在后可缩写). 题目(英文题目第一字母大写，其它均小写)：副标题(如果有). 刊名(全称), 年, 卷(期): 页码` |
| 会议论文 | `[编号] 作者. 文章题目(英文题目第1字母大写，其它均小写)：副标题(如果有)//Proceedings of the …(会议名称). 会议召开城市, 会议召开城市所在国家, 年: 页码` |
| 文集 | `[编号] 作者. 文章题目(英文题目第一字母大写, 其它均小写): 副标题(如果有)//编者. 文集标题. 出版地: 出版社, 出版年: 页码` |
| 书籍 | `[编号] 作者. 书名: 副标题(如果有). 版次(初版不写). 出版社地点: 出版社, 出版年` |
| 学位论文 | `[编号] 作者. 文章题目[博士学位论文/硕士学位论文]. 单位地点: 单位名称, 年.` |
| 技术报告 | `[编号] 作者. 文章题目(英文题目第一字母大写，其它均小写). 单位地点: 单位, 技术报告: 报告编号, 年` |
| 专利 | `[编号] 专利拥有人. 专利名称，专利授权国家，专利授权日期` |
| 中文文献对照例 | `Zhou Yong-Bin, Feng Deng-Guo. Design and analysis of cryptographic protocols for RFID. Chinese Journal of Computers, 2006, 29(4): 581-589 (in Chinese) (周永彬, 冯登国. RFID 安全协议的设计与分析. 计算机学报, 2006, 29(4): 581-589)` |

所有文献按引用顺序排序并核查准确；未覆盖的文献种类尽量提供完整信息；中文文献需译成英文（保留中文）。

## 7. 摘要撰写规范（四条）——How I did it 是重点

摘要必须包含四部分内容：

1. **目的/要解决的问题 (What I want to do?)**：开头明确交待目的；避免第一句话重复题目的内容；
2. **解决问题的方法及过程 (How I did it?)**：**重点，要详细**。应结合论文中的公式、实验框图阐述，避免泛泛而谈、只有定性描述；
3. **主要结果及结论 (What results did I get and what conclusions can I draw?)**：结合图表数据说明，做到言之有物、有根有据；必要时可与他人最新研究结果比较，突出贡献；
4. **本文的创新、独到之处 (What is new and original in this paper?)**：创新点要明确可定位。

**摘要贡献部分必须有数据支持**：不得出现"…大大提高"、"…显著改善"等定性描述；正确写法为"比…提高 X%""在…上改善 X%"。

**文字要求**：
- 尽量用短句；
- 描述作者工作用过去时，陈述结论用现在时；
- 用动词主动语态（如 `A exceeds B` 优于 `B is exceeded by A`）；
- 英文摘要与中文摘要内容对应，英文表述规范、符合英文习惯；
- 英文摘要 500 词（论文稿文末；修改稿要求 500 词以上）。

## 8. 英文背景介绍（Background，文末必附）

每篇文章正文后附 **400 词左右的英文背景介绍**（小5号 Times New Roman），内容须包含：

1. 本文研究的问题属于哪一个领域什么问题，该类问题目前国际上解决到什么程度；
2. 本文将问题解决到什么程度；
3. 课题所属的项目；
4. 项目的意义；
5. 本研究群体以往在这个方向上的研究成果；
6. 本文成果是解决大课题中的哪一部分（涉及项目、基金、研究计划时，英文名称书写正确）。

## 9. 作者简介要求

- 第一作者须提供照片电子图片（1 寸），文末附中英文作者简介。
- 英文作者介绍内容包括：出生年、学位（或目前学历）、职称、主要研究领域（与中文作者介绍的研究方向一致）。
- 修改稿还应附所有作者中英文简历（姓名、性别、出生年月、学历、职称、研究方向、是否中国计算机学会会员），以及联系人电话和 E-mail。

## 10. 编辑部内容检查（投稿前自查）

1. **政治方面**：有无与当前国家提法相悖之处；有无泄密问题（保密成果不予报道，保密单位成果需隐去真实名称以别名代替）；有无主权问题（边境、岛屿等）。
2. **著作权**：内容是否作者本人成果；引用他人文章是否注明出处；是否一稿双投；署名有无争议。
3. **专业术语**：按审定名词标准检查术语规范性；文风端正；中英文摘要是否准确反映原文。
4. **文字**：题目明确反映思想和方法；原文流畅；中英文无错误；公式符号无疏漏；量符合法定计量单位；矢量黑体、标量白体；图表量、线、序无误、位置正确；图表中英文一般需译为中文；参考文献引用位置正确、项目齐全。
5. **规范化**：文中表达同一量的外文字母大小写、正斜体一致准确；上下脚标正确；符号使用规范。

## 11. 综述论文撰写要点（针对"综述"投稿）

- 综述结构：引言、问题与挑战、研究现状分析、未来研究方向、结论。
- **以分析、对比为主**，避免堆砌文献或一般性介绍、叙述；要求题材新颖、重在分析评论。
- 综述摘要同样遵守四要素规范（How I did it 中应交代综述范围、方法、结论）。
- 收录论文数量与时间范围建议量化（如"对近 200 篇论文进行系统梳理"）。

## 12. 投稿前 CheckList（修改稿提交前逐项核对）

- [ ] 模板要素齐全：中英文题目一致；作者/单位中英文一致；摘要、关键词（5-7 个）、中图法分类号
- [ ] 正文六要素/综述五段结构齐全；引言与相关工作分离
- [ ] 图表均先在正文中表述（"如图 X 所示"），坐标轴有名称和刻度值；图例/坐标中文；表头中文；图为矢量图
- [ ] 公式、符号规范：斜体/黑体/白体区分；单位标准格式；首次出现缩写有全称、符号有解释
- [ ] 参考文献顺序与引用顺序一致、项目齐全、期刊会议全称、中文文献中英对照
- [ ] 摘要贡献数据化（"比…高 X%"），无"大大提高"类定性表述
- [ ] 文末英文摘要 ≥500 词、中文对应；Background 400 词英文
- [ ] 作者简介（中英文）+ 第一作者照片；基金项目号
- [ ] 修改稿 DOC+PDF 双格式；页面有页码
