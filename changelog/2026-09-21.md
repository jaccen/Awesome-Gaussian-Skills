## 1. AIGC Trace Removal

Scanned every repository file for AIGC provenance markers and stripped them:

- **29 text files**: removed YAML frontmatter `AIGC:` blocks (`ContentProducer`, `ContentPropagator`,
  `ProduceID`, `PropagateID`, `ReservedCode1/2`) and trailing `> AI生成` lines.
  Backed up to `.temp/aigc-backup/`; re-scan confirms **0 hits**.
- **21 JPEGs** in `新建文件夹/`: discovered that an earlier PowerShell-based pass had truncated them to
  476–700 bytes. Root cause was loss of image data in the old APPn-stripping logic. Restored from backup
  and re-stripped metadata only (~405 bytes/file), with SOI/EOI/size triple verification. 0 failures.
- New reusable tooling: `scripts/strip-aigc.py` (Python; cross-platform, verified against real images).

## 2. Multi-Channel Paper Harvest

New pipeline `scripts/harvest_new_papers.py` → `scripts/verify_candidates.py` → `scripts/enroll_new_papers.py`.

**Channels**
1. **arXiv API** — six query forms: `cat:cs.CV`, `cat:cs.GR`, `cat:cs.RO`, full-corpus `all:"gaussian splatting"`,
   `abs:"3D Gaussian Splatting"`, `ti:"Gaussian Splatting"`, all restricted to a 150-day submittedDate window.
2. **Semantic Scholar Graph API** — cross-source backfill (opt-in via `--s2`).
3. Existing `scripts/daily_arxiv_scan.py` remains as the daily cron path.

**Result**: 395 candidates → after verification **162 new methods** admitted (141 rule-accepted + 25
manually adjudicated − 4 duplicates).

### Verification protocol applied (R1–R6)

| Rule | Meaning | Rejected |
|---|---|---|
| R1 | Exclude survey / review / benchmark / dataset | 18 |
| R2 | Method name must be the paper's **self-stated** name, reproduced in the abstract | 67 |
| R2d | Multi-word names need a proper-noun token — blocks `Capacity-Controlled`, `Scene-Level` | (in R2) |
| R3 | Abstract must contain both `gaussian` and `splat` | 16 |
| R4 | Deduplicate against existing names / arXiv IDs | 20 |
| R5 | Reject derived suffixes `-v2` / `-2` / `-full` / `-ICRA` unless self-stated | — |
| R6 | Title must reference GS, else the method likely just uses GS as a tool | 114 → reviewed |

114 borderline items were read individually against their abstracts; 25 were adjudicated as genuine GS
methods (e.g. `RawSLAM`, `Elastic Triangle Splatting`, `TSOG`, `Ground4D`, `Instant NuRec`, `NoDrift3R`)
and enrolled via an explicit, commented whitelist; the rest were dropped as out of scope
(e.g. `HybridSim`, `RealVDeblur`, `OmniStyle-INR`, `MR-Compare`).

### Bug fixed during harvest

`daily_arxiv_scan.py` and the first harvester both formatted the date range as `2026-04-24`
(ISO with hyphens). arXiv requires `YYYYMMDDHHMM`, so every query returned HTTP 400 and silently
yielded zero results. Fixed in both scripts.
