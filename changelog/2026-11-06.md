## Method Highlights

- **GSExplorer** — Interactive world generation built on a persistent 3D Gaussian world state: multimodal rendering conditions feed a video generator, output is fused back via a SLAM-based reconstruction backend with inconsistency filtering and cross-chunk bundle adjustment (Camera Control 99.07 on single-step extrapolation).
- **SHield** — First non-blind, decoder-free 4DGS watermarking; embeds full-resolution RGB payloads in canonical SH coefficients with closed-form recovery (Pearson r ≥ 0.991 across 150 models).
- **EndoS3** — Gaussian-Splatting semantic SLAM for endoscopy; instance-level motion decomposition + per-instance warp field + semantic node allocation, SOTA on CRCD++/SemSup.
- **IGSW** — Multi-weather urban 4D scene with intrinsic-decoupled Gaussian modeling and structure-preserving weather refinement (nuScenes/Waymo).
- **GaussianRenderFormer** — Rasterizer-free transformer that renders 3D Gaussian splats directly (each Gaussian a token).
- **AbacusGS** — Stores blending order in the scene layout so splats no longer need per-frame CPU sorting (4.5× faster in an OpenGL viewer, 17 B/splat format).
