## 通用投稿格式规范

### IEEE 期刊通用格式（适用于大多数IEEE Transactions）

| 要素 | 规范 |
|------|------|
| 模板 | IEEEtran.cls（单栏 for review / 双栏 for camera-ready） |
| 字体 | Times New Roman, 10pt（正文）；公式中斜体变量 |
| 摘要 | ≤250 词，第三人称，不引用参考文献，不包含图表引用 |
| 关键词 | 3-6 个（Index Terms），按字母排序 |
| 页数 | 一般无硬性限制，建议 8-14 页（含参考文献）；超页可能收额外费用 |
| 参考文献 | IEEE 标准格式：`[1] A. Author, "Title," Journal Name, vol. X, no. Y, pp. Z1-Z2, Month Year` |
| 图表 | 单栏宽度 3.5 inch / 双栏宽度 7.16 inch；矢量图（PDF/EPS）；300 dpi 以上 |
| 公式 | 连续编号，居右：`(1)`、`(2)`；矩阵/向量粗体 |
| 投稿系统 | ScholarOne Manuscripts 或 IEEE Author Portal |
| 审稿制度 | 双盲（部分）或单盲（多数） |
| 查重 | iThenticate 查重，重复率建议 < 15% |

### ACM 期刊通用格式（适用于ACM Transactions系列）

| 要素 | 规范 |
|------|------|
| 模板 | acmart.cls（sigconf / acmsmall / acmlarge） |
| 字体 | ACM Noto Serif / Linux Libertine, 9-10pt |
| 摘要 | ≤250 词，概念-方法-结果-贡献四要素 |
| 关键词 | CCS（Computing Classification System）分类 + 自由关键词 |
| 页数 | 通常 12-20 页（两栏）；无严格限制但建议精简 |
| 参考文献 | ACM Reference Format：`[1] Author Name. Year. Title. Journal Name, Volume, Issue, Article No., Pages.` |
| 图表 | 彩色图免费（在线版）；单栏 3.33 inch / 双栏 7.0 inch |
| 开放获取 | 可选 OA（APC 约 $1500-$3000） |
| 投稿系统 | ACM Manuscript Central（ScholarOne） |
| 审稿制度 | 单盲或双盲（视期刊） |
| 附属材料 | 可附 Supplementary Materials（附录、视频、代码） |

### Springer 期刊通用格式

| 要素 | 规范 |
|------|------|
| 模板 | Springer Nature LaTeX template（sn-journal.cls） |
| 字体 | Times New Roman, 10pt |
| 摘要 | ≤250 词，结构化（Background → Methods → Results → Conclusions） |
| 关键词 | 4-6 个 |
| 页数 | 无严格限制，建议 15-30 页 |
| 参考文献 | Springer Basic / Vancouver style：`[1] Author A (Year) Title. Journal Name, vol(Issue): pages` |
| 开放获取 | 可选 OA（APC 约 $2000-$5000） |
| 投稿系统 | Editorial Manager（editorialmanager.com） |

## 投稿格式要点速查表

### 摘要撰写（所有英文期刊通用）

英文摘要应包含四要素，与中文期刊相同：

1. **Background/Motivation**：研究背景与问题（1-2 句）
2. **Approach/Method**：方法与过程（2-3 句，重点描述）
3. **Results**：主要结果与数据（2-3 句，量化贡献）
4. **Contribution/Impact**：创新点与意义（1 句）

**关键规范：**
- 第三人称，被动语态为主（"A novel method is proposed..." 或 "This paper presents..."）
- ≤250 词（IEEE）/ ≤200 词（ACM）/ 视期刊而定
- 不引用参考文献
- 不包含图表引用
- 不使用未定义缩写

### 图表规范（英文期刊通用）

| 要素 | 规范 |
|------|------|
| 图格式 | 矢量图（PDF/EPS），300 dpi 以上 |
| 单栏宽度 | IEEE: 3.5 inch / ACM: 3.33 inch / Springer: 3.2 inch |
| 双栏宽度 | IEEE: 7.16 inch / ACM: 7.0 inch / Springer: 6.7 inch |
| 图注 | Figure 1. Caption text. （首字母大写，句号结尾） |
| 表格 | Table I. Caption text. （IEEE 用罗马数字；ACM 用阿拉伯数字） |
| 彩色图 | 在线版免费；纸质版可能收费（IEEE/ACM 均如此） |
| 子图 | (a) Sub-caption. (b) Sub-caption. 居中放置 |

### 参考文献格式对比

| 出版社 | 格式示例 |
|--------|---------|
| IEEE | `[1] A. B. Author, C. D. Author, and E. F. Author, "Paper title," IEEE Trans. Pattern Anal. Mach. Intell., vol. 45, no. 3, pp. 1234--1250, Mar. 2023.` |
| ACM | `[1] Author Name, Author Name, and Author Name. 2023. Paper title. IEEE Trans. Pattern Anal. Mach. Intell. 45, 3 (March 2023), 1234--1250.` |
| Springer | `[1] Author, A. (2023). Paper title. IEEE Transactions on Pattern Analysis and Machine Intelligence, 45(3), 1234--1250.` |
| Elsevier | `[1] Author A, Author B, Author C. Paper title. IEEE Transactions on Pattern Analysis and Machine Intelligence. 2023;45(3):1234-1250.` |

### 投稿前通用 CheckList（英文期刊）

- [ ] 原创性确认：未在正式出版物刊载过，未一稿多投
- [ ] 模板正确：IEEEtran / acmart / Springer Nature
- [ ] 摘要 ≤250 词，四要素齐全，第三人称
- [ ] 关键词 / Index Terms / CCS 分类已标注
- [ ] 图表矢量格式，分辨率达标，图注规范
- [ ] 参考文献格式与出版社一致
- [ ] 公式连续编号，变量斜体，矩阵/向量粗体
- [ ] 查重 < 15%（iThenticate）
- [ ] Supplementary Materials（视频/代码/附录）按期刊要求准备
- [ ] Cover Letter 简明说明创新点
- [ ] 推荐 3-5 位审稿人（部分期刊要求）
- [ ] 利益冲突声明（如适用）
- [ ] 数据可用性声明（Data Availability Statement）

## 与中文期刊的关键差异

| 维度 | 英文期刊 | 中文期刊 |
|------|---------|---------|
| 语言 | 英文 | 中文（附英文摘要） |
| 模板 | IEEEtran / acmart / Springer | 各期刊自定义 Word 模板 |
| 摘要 | ≤250 词，四要素 | 250-500 字，四要素 |
| 关键词 | Index Terms / CCS | 5-8 个，中英文对应 |
| 参考文献 | IEEE / ACM / Vancouver 格式 | GB/T 7714 |
| 审稿制度 | 双盲（多数IEEE/ACM） | 单盲（多数中文期刊） |
| 查重要求 | iThenticate < 15% | 各期刊不同（计算机研究与发展<10%） |
| 开放获取 | 可选OA（APC $1500-$5000） | 通常免费 |
| 审稿周期 | 3-12 个月（期刊>会议） | 3-6 个月 |
| 页数 | 8-20 页（两栏） | 6000-15000 字 |
| 补充材料 | 视频/代码/附录常见 | 一般不附 |
| Cover Letter | 必须 | 一般不需要 |
| 推荐审稿人 | 部分要求 | 一般不要求 |
